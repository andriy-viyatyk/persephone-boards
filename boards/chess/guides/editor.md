# Playing Agent Chess

## Start a game

1. Open the **Agent Chess** board.
2. Click **New game: I'm White** or **New game: I'm Black**.
3. Ask your agent to play, for example: *"Let's play chess on the Agent Chess board in
   Persephone. You are Black."* The agent finds the board and waits for your move.

The agent learns about each of your moves from the board, so you only need to ask once. If you
leave the game for a few minutes, the agent pauses so it does not hold up your conversation; tell
it to continue when you are back.

## Moving

- **Drag** a piece to its square, or **click** the piece and then the square. Dots show the legal
  squares; a ring shows a capture.
- When a pawn reaches the last rank, pick the promotion piece.
- While the agent is thinking, the status says **Agent is thinking…** and your pieces are locked.

## Toolbar

| Button | What it does |
|---|---|
| New game: I'm White / I'm Black | Starts over; the agent is told |
| Take back | Undoes your last move and the agent's reply to it (or a resignation) |
| Resign | Ends the game |
| Flip | Turns the board around |
| Copy PGN | Copies the game in PGN, to analyse it elsewhere |

## Chat

Type in **Message your agent…** and press Enter — the agent receives it and can answer in the
chat. Its comments and arrows appear on the board while you play.

The game, chat and orientation are kept when the board reloads or Persephone restarts.
