# What's New

## 1.1.0

- Interface text moved to a language pack (`lang/en.json`) so the board can be translated; requires Persephone with board bridge 1.36.0.

## 1.0.1

- Added offline, read-only X.509 certificate, CSR, PKCS#7, and PKCS#12 inspection.
- Added `certificate.view` capability handling with leaf-first chain rendering and page-state restore.
