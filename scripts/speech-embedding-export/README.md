# Speech embedding export research

This directory contains research tooling, not a board or a distributable model. The user supplied the TF Hub `google/speech_embedding/1` archive from `https://tfhub.dev/google/speech_embedding/1?tf-hub-format=compressed` in `_test/wake-export/google-release/`. Archive SHA-256: `0f626c42009c1eb916401b7b2800229a211e43100115bc591b9afbf1b60da27f`. Kaggle API metadata saved at `_test/wake-export/google-release/kaggle-model.json` identifies the TensorFlow1 instance, version 1, as Apache 2.0. The release description documents 16 kHz float32 waveform input in [-1,1] and its built-in 32-bin log-mel (25 ms window, 10 ms step, 60–3800 Hz). Cite the module as “speech_embedding” by Google, Kaggle/TF Hub, Apache-2.0; research paper: James Lin, Kevin Kilgour, Dominik Roblek, Matthew Sharifi, “Training Keyword Spotters with Limited and Synthesized Speech Data” (2020), https://arxiv.org/abs/2002.01322. The JS frontend reproduces these settings.

Use Python 3.12 and the versions in `requirements.txt`. Run `python scripts/speech-embedding-export/export.py` in the supplied virtual environment. It loads the release's empty tag set, prunes its waveform signature at the internal log-mel `Squeeze`, freezes the Google backbone, and converts to ONNX opset 13. The model and downloaded data stay under ignored `_test/wake-export/`. The output's input is `Squeeze:0`, float32 `[1,76,32]`; its output is `embeddings_apply_default/MudpuppyLite/Conv_18/Conv2D:0`, float32 `[1,1,1,96]`. The source release public input is float32 `[batch,samples]`; output is float32 `[batch,time,1,96]`.

`frontend.mjs` independently computes the release log-mel frontend: 16 kHz, 400-sample periodic Hann, 160-sample hop, 512-point real FFT magnitude, 32 TensorFlow-style mel bins from 60 to 3800 Hz, natural log of mel magnitude plus 0.001. For 12,800 samples the release produces 78 frames; its single output uses the first 76. The prototype uses the last 76 frames of its own frontend; the clean pipeline uses the source module's first 76. `session-compare.mjs` replays the existing 16 kHz mono `last-session.wav` in 80 ms chunks. It independently builds templates for each pipeline from the four enrollment WAVs, then applies the prototype's trim, rolling 0.8 s window, subsequence DTW and 1.5 s refractory logic. The prototype's openWakeWord files are used only as the comparison reference. It reports numeric trace summaries, event times and region margins; it never writes to or copies audio from the prototype.

The upstream model is licensed Apache-2.0. Before distribution, include the Apache notice and attribution above and review the export tool dependency notices. The reviewer recorded Gate 1 as passed equivalent because the clean export reproduces the Google release (cosine 1.000000) and prototype event-set equality is not a valid ground-truth criterion. The board ships the model with the Apache attribution. Gate 2 selected Node-compatible `onnxruntime-web` 1.22.0 WASM after measuring 5.72% of one core for one active stream and 2.09% per stream with two concurrent streams; see `doc/tasks/BT-083-wake-word/README.md` for the full measurements.
